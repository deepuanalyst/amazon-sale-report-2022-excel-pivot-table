<h2>📌 Project Overview</h2>

<p align="center">
  <img src="amazon-sale-report-2022-excel-pivot-table/Screenshot (861).png" alt="Amazon Sales Dashboard Screenshot" width="900">
</p>

<p>
  Built an interactive sales dashboard analyzing <b>128,000+ Amazon order records</b> 
  (March–June 2022). The project covers the full analytics workflow — from raw data 
  cleaning to dynamic dashboard reporting — using Excel and Power Query.
</p>

<h2>🛠️ Tools & Skills Used</h2>
<ul>
  <li>Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)</li>
  <li>Power Query (Data Cleaning, Transformation, M Language)</li>
  <li>Dashboard Design & Data Storytelling</li>
</ul>

<h2>🧹 Data Cleaning Highlights</h2>
<ul>
  <li>Fixed date format mismatches (dd-mm-yy locale correction)</li>
  <li>Handled nulls in Courier Status, Amount, ship-city using logic-based imputation</li>
  <li>Standardized inconsistent category and state text casing</li>
  <li>Resolved duplicate and mismatched Fulfilment/fulfilled-by records</li>
</ul>

<h2>📈 Key Insights</h2>
<ul>
  <li><b>Set</b> and <b>Kurta</b> categories generated the highest revenue</li>
  <li><b>April</b> was the strongest sales month in the period analyzed</li>
  <li><b>Maharashtra</b> and <b>Karnataka</b> led state-wise sales</li>
  <li><b>Bengaluru</b> and <b>Hyderabad</b> were the top-performing cities</li>
  <li><b>Sunday</b> recorded the highest order volume, indicating weekend shopping behavior</li>
</ul>
